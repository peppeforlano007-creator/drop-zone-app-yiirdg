Pickup-point accounts must ALWAYS be able to register an item's return (reso) or missed pickup (mancato ritiro). All other card operations (refunds, review tools) are admin only.

**Why:** owner's rule when listing remaining gates before card activation (2026-10-26).
**How to apply:** never gate return/no-show recording behind admin or card state; refund screen/functions stay admin-only.
